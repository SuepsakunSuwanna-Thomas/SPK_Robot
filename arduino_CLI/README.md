# 🚀 SUPERSONIC RP2350 PORTABLE PIPELINE (V6 ELITE)

ชุดพัฒนาหุ่นยนต์ความเร็วสูงสำหรับบอร์ด **RP2350 (Pico 2)** เวอร์ชัน **100% Standalone Portable** 
ออกแบบมาเพื่อประสิทธิภาพสูงสุดในการแข่งขัน พร้อมระบบ Nitro Engine ที่คอมพายเร็วที่สุด

## 🌟 ฟีเจอร์เด่นในเวอร์ชัน V6 ELITE
- **Double Entry Mode**: สลับใช้งานไฟล์หลักระหว่าง `main_B.ino` และ `main_T.ino` ได้อย่างอิสระ
- **Clean & Accurate Logs**: แสดงเฉพาะขั้นตอนสำคัญเพื่อให้หน้าจอสะอาดตา แต่ยังคงแจ้งเตือนทุก Error ที่เกิดขึ้น
- **Global Timing System**: ระบบจับเวลาอัจฉริยะที่โชว์เวลาจริงตั้งแต่วินาทีแรกที่เริ่มสั่งงานจนจบกระบวนการ
- **Smart Build-Only**: สามารถ Rebuild ระบบเพื่อเช็ค Error ได้โดยไม่ต้องเสียบสายบอร์ด
- **Nitro Engine V6**: ระบบคอมพายแบบ Incremental ที่ใช้เวลาเพียง **3-5 วินาที** ในการอัปโหลดโค้ดใหม่

## 📂 คำสั่งการใช้งานผ่าน CMD

### 1. การ Rebuild ระบบใหม่ (ใช้เมื่อเพิ่มไฟล์/Library หรือเช็ค Error)
*   **`.\FORCE_REBUILD.bat`** (ไม่ใส่ต่อท้าย)
    *   **Build Only**: ทำการล้าง Cache และสร้างระบบใหม่เพื่อเช็ค Error **โดยไม่อัปโหลดลงบอร์ด**
    *   **Safe Mode**: ไม่มีการเตะบอร์ดเข้าโหมด Bootloader (ประหยัดเวลาและปลอดภัย)
*   **`.\FORCE_REBUILD.bat B` หรือ `T`**
    *   ทำการ Rebuild ระบบใหม่ทั้งหมดของโหมดที่เลือก และ **อัปโหลดลงบอร์ดทันที**

### 2. การอัปโหลดแบบเร็ว (Fast Upload - ใช้เป็นหลักขณะเขียนโค้ด)
*   **`.\FAST_UPLOAD.bat B`** : อัปโหลดโค้ดโหมด B (ใช้เวลา ~4-5 วินาที)
*   **`.\FAST_UPLOAD.bat T`** : อัปโหลดโค้ดโหมด T (ใช้เวลา ~4-5 วินาที)

## 📊 การอ่านค่าเวลา (Timing Summary)
*   **NITRO TOTAL**: เวลาที่ใช้เฉพาะส่วนการจัดการโค้ดและการ Flash (ความเร็วของ Engine)
*   **TOTAL PROCESS**: **เวลาจริงทั้งหมด** ตั้งแต่วินาทีที่คุณกด Enter จนจบกระบวนการ (รวมเวลาที่ระบบ Scan ข้อมูลเครื่อง)

## 📁 โครงสร้างสำคัญ
- `libraries_User/`: สำหรับเก็บ Library ส่วนตัวของคุณ (ระบบจะสแกนให้อัตโนมัติ)
- `sketch/main_B/`: โฟลเดอร์เก็บโค้ดหลักของโปรเจกต์
- `portable_tools/`: รวมเครื่องมือพัฒนาทั้งหมด ไม่ต้องติดตั้งอะไรเพิ่มในเครื่อง
